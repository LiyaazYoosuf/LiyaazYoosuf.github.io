Adhabeebas Game

2024

Details

An educational video game developed for the purpose of teaching Dhivehi figurative phrases to children. The game makes use of stories depicting the meaning of each phrase. It was developed using Godot Engine. 3D Character models and animations were created using Blender, while 2D UI assets were made using Inkscape. The game was developed as part of the Final Year Project for the course "Bachelor of Computer Science" at the Maldives National University.The project is currently being remade to improve quality.
